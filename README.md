# Student Management System

A Django web application to manage students with full CRUD functionality (Create, Read, Update, Delete).
this App helps School to manager student's information and register student using interface
---

## Features
- Add new students:         to Register student in our system
- View a list of students:  to view list of registered students
- Update student details:   to change details of registered students
- Delete students:          to Delete student if not still existing
- PostgreSQL database integration
- Environment variables managed securely with `python-decouple`

---

## Tech Stack
- **Backend:** Djangogit 
- **Database:** PostgreSQL
- **Frontend:** Django templates (HTML, CSS)
